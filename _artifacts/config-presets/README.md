# Litematica 常用别名增量包

采用 UTF-8 JSON。运行时目录为当前游戏实例的 `config/spark_fix/`，文件名统一为：

`常用别名_<主题>_<方案>.json`

例如：`常用别名_默认_蓝图.json`、`常用别名_打印_快捷操作.json`。

## 格式

```json
{
  "litematica-printer::0::打开设置菜单": ["打印机设置", "打印机菜单"]
}
```

- 文件内容只有“稳定 key → 新增别名数组”。只填写需要补充别名的设置，其余设置不写入。
- key 是“配置处理器 ID::配置索引::配置原名”，仅用来定位设置。上例中的“打开设置菜单”是 key 的组成部分，不会导入为主名。
- 数组只放新增搜索词，不放原名、主名、已有别名、设置值或全量配置。包内也不包含名称字段、来源元数据和完整设置清单。
- 生成及导入时跳过与原名/主名重复的内容，也去掉仅空格、标点或大小写不同的重复词。

读取时按文件名排序，新增别名去重后追加，未知 key、空别名及非法条目跳过。同一文件里的同一设置只补入一次，因此手动删除的别名不会在下次打开时重新出现。以后继续添加时创建另一份增量包，不导出当前完整配置。卡片主名继续由原有主名设置管理。

合并后的别名与导入记录在关闭投影设置页时保存到 `config/spark_fix.properties`，沿用 URL-safe Base64 与约 1800 字符分段存储。JSON 本身保留可读的中文，不使用 Base64。

## 用户自定义别名

在别名编辑页确认新增、修改或删除后，关闭投影设置页时统一保存到 `config/spark_fix/常用别名_自定义.json`，格式也是“稳定 key → 别名数组”。只保存个人别名；默认包内容、主名和设置值不写入此文件。删除最后一个别名后，相应设置项也从文件移除；没有自定义别名时文件为 `{}`。

每次打开投影设置页读取此文件，支持手动编辑和复制到其他实例；它不使用普通增量包的一次性导入标记。未安装模组的条目保留在文件中，当前页面忽略这些条目。文件格式有误时保留原文件并继续使用已有缓存。

删除自定义文件表示清除其中已保存的个人别名，Properties 缓存不会再把旧词恢复回来；主名和默认包别名保留。页面尚未关闭时删除文件，本轮新添加的别名仍会保留，关闭页面后重新生成的自定义文件只包含这些新词。没有新词则写入 `{}`。检查发生在打开投影页、打开/确认别名编辑页和关闭投影页时。

Properties 额外记录上次保存的个人别名来源，沿用 URL-safe Base64 和分段格式，用来处理关闭页面或退出游戏后删除文件的情况。旧版本没有这份记录且自定义文件已缺失时，也会清除当前可识别的个人别名缓存，不再从缓存重建旧词。

## 第一份实际预设

`2026-09-27/常用别名_默认_蓝图.json` 来自 `26.2wmd` 实例已经捕获并保存的 297 项设置：Litematica 259 项，打印扩展 38 项。仅为其中 163 项补充 388 个新增搜索别名。

别名统一使用“蓝图”，补充轻松放置、选区、材料清单、渲染、打印范围和打印模式等搜索词。没有复制世界配置、网络地址、目录设置或其他选项值。捕获清单在项目 `_analysis/2026-09-27-litematica-module-filters/captured-options.json`。

来源版本：Litematica 0.28.8，Litematica-Printer 2.4+20260723.34。打印扩展的实际 Fabric ID 是 `litematica-printer-all`，注册配置处理器 ID 是 `litematica-printer`；预设使用后者以匹配现有稳定 key。

生成工具：`_tools/Build-DefaultLitematicaAliases.py`，只读指定实例，输出项目内的候选文件和清单；不会自动安装模组或修改实例配置。

## 范围预设

[`2026-10-03/常用别名_默认_范围.json`](2026-10-03/常用别名_默认_范围.json) 只追加“半径”替换为“范围”的别名：二改的“打印机工作半径 → 打印机工作范围”“半径模式 → 范围模式”，以及三改的“工作半径 → 工作范围”。已核对 `26.2wmd` 实例的设置 key 和三改原生中文名称。

保留原始 key，仅增加上述三个别名，不覆盖主名或设置值。索引变化时沿用导入器按处理器 ID 和唯一配置原名匹配的规则。

将文件放入实例的 `config/spark_fix/`，重新打开投影设置页即可导入。可与蓝图预设同时使用，重复别名会去重。
